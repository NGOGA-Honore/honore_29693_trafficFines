# Data

## Source

Montgomery County of Maryland, *Traffic Violations* (electronic traffic violations issued in the county, updated daily).

- Portal: https://data.montgomerycountymd.gov/d/4mse-ku6q
- Data.gov record: https://catalog.data.gov/dataset/traffic-violations (formats: CSV, JSON, XML, KML, GeoJSON)
- Size: a 2015-2017 extract of this data has 1,276,580 rows and 35 variables (https://rdrr.io/github/trinker/exampledata/man/traffic_violations.html). The live dataset is larger, well above the "few hundred records" requirement.
- Personal information: the publisher states that information that can uniquely identify the vehicle, the owner or the officer is not published. Race, Gender and Driver City are dropped before loading, and driver and vehicle keys are generated.
- Licence: the Data.gov record does not state one. The data is public open government data, used here for study only.

## What the dataset does not contain

The dataset has violations only. It has no fine amounts and no payments.

- **Fine amounts** come from the `violation_type` fine schedule that I define (base fine by severity). They are design values, not official Rwandan amounts.
- **Payments** are generated by the system's own PL/SQL procedures during testing and the demonstration. They are simulated data and are labelled that way.
- Only rows with Violation Type = Citation become fines. Rows marked Warning are kept as violations without a fine.

## Loading size

The project loads a subset (a few thousand to tens of thousands of rows) of the CSV, which is enough to show the rules, the arrears report and the application. The full file is kept out of this repository because GitHub rejects files over 100 MB.

## Column mapping (source column to target table)

| Source column | Target | Note |
|---|---|---|
| Date Of Stop, Time Of Stop | `violation.stop_date`, `violation.stop_time` | Used for the duplicate-ticket rule |
| Latitude, Longitude | `violation.latitude`, `violation.longitude` | Location of the violation |
| Accident, Fatal | `violation.accident_flag`, `violation.fatal_flag` | Severity context |
| Violation Type | `violation.violation_kind` | Warning or Citation; only Citation creates a fine |
| Charge | `violation.charge_code` (FK to `violation_type`) | Numeric charge code |
| State | `vehicle.reg_state` | State of registration |
| VehicleType, Year, Make, Model, Color | `vehicle.*` | Vehicle details |
| Driver State | `driver.state` | The only driver attribute kept |
| Race, Gender, Driver City | not loaded | Dropped: demographic or location details of a person |
| (generated) | `driver.driver_id`, `vehicle.vehicle_id` | Surrogate keys created during loading |
| (generated) | `fine.*`, `payment.*` | Created by the PL/SQL rules |
